# Dashboard

## 一覧と検索

Activity Bar の Webview に Tickets、Unsynced、Settings があります。Tickets でプロジェクトと子プロジェクトの対象範囲を選びます。チケット行をクリック（選択）すると即座に右側エディタで Markdown 編集文書を開き、同時にサイドバー下部に詳細ドロワー（初期高さ `48%`）を展開して概要・コメント履歴を表示します。未同期キューと復旧操作は [保存と同期](offline-sync.md) と [障害復旧](sync-recovery.md) を参照してください。

- プロジェクトの選択肢は名前または識別子で絞り込めます。検索欄の入力だけで現在のプロジェクトは切り替わりません。子プロジェクトを含めるトグル（`codicon-list-tree`）はツールチップに ON/OFF 状態を表示します。
- ビュータイトル（`view/title`）のアクション（更新 `redmine-client.refreshTickets`、新規作成 `redmine-client.createTicketFromDashboard`、表示密度切替 `redmine-client.toggleCompactMode`）で一覧操作を行います。Webview ヘッダー内の重複する更新・新規作成・表示密度ボタンは持たず、プロジェクト選択と子プロジェクト階層トグルのみを配置します。表示密度切替（標準モード：2行＋進捗バー / コンパクトモード：1行のみ）の状態は Webview 状態として保持します。
- チケット検索は選択プロジェクトの範囲または全プロジェクトを対象にできます（入力デバウンス `150ms`）。件名・説明の結果を統合し、同じチケットの重複を除きます。数値 ID の直接一致を優先し、`#123` 形式は ID 指定として扱います。検索結果は階層を展開した一覧で表示します。
- クイックフィルターは `Tickets` タブ専用の 4 種（自分のチケット・未完了〔既定 ON〕・期限超過・高優先度）とし、永続フィルターとともに読み込み済みのチケットに適用します。`未同期` チップは廃止し、未同期アイテムの一覧表示は `Unsynced` タブへ集約します。`Unsynced` タブではプロジェクト選択やクイックフィルターによる除外を行わず、すべての未同期変更を表示し、1件以上ある場合はリスト上部に「すべて同期」バーを表示します。表示中、読み込み済み、全件の件数を区別し、ゼロ件時はフィルターをクリアする操作（`clear-filters-btn`）を表示します。追加読み込みと検索のページングは一覧の表示順設定から独立します。
- チケット行には左端のトラッカー識別バー、優先度インジケータ、枠線付きステータスバッジ、担当者、期日（`MM/DD`・超過強調。完了ステータスは超過扱いとしない）、進捗バー、親子ツリーガイド線を表示します（ホバー時のクイックアクションは配置しません）。行クリックで該当チケットの Markdown 編集文書を開き、`ArrowDown` / `ArrowUp` ではサイドバーのキーボードフォーカスを維持したまま（`preserveFocus: true`）編集文書と詳細ドロワーを切り替え、`ArrowRight` / `ArrowLeft` で子チケットの展開・折りたたみができます。`Escape` キーで詳細ドロワーを閉じます。
- ビュータイトルの更新アクション（`redmine-client.refreshTickets`）は更新中にスピン表示・`aria-busy` 状態となり、完了時に通知します。クイックフィルターで子チケットが一致した場合は折りたたまれた親チケットを自動展開して表示します。
- ビュータイトルの `+` アクション（`redmine-client.createTicketFromDashboard`）は選択中プロジェクトを引き継いで新規チケットの即時ドラフトを開き、同期完了まで一覧先頭に `#NEW` 行（`#tickets-badge` 対象）として表示します。Markdown 編集中の変更（既存チケット・新規下書き、`done_ratio` 進捗率を含む）も `300ms` デバウンス後に一覧・未同期件数・詳細ドロワーへ即時反映します。
- 詳細ドロワーはサイドバー下半分（リスト `52%` / 詳細 `48%`）に展開し、2段構成のコンパクトヘッダー（1段目: トラッカー色バー・`#id`・1行省略件名・閉じるボタン、2段目: プロジェクト名・未同期インジケータ・`同期` と `ブラウザで開く` の 2 アクション）を持ちます。概要タブではステータス・優先度・担当者・期日を 2 列の読み取り専用メタグリッドで表示し、未同期変更がある場合は警告バナーと説明欄を表示します。コメントタブでは「＋ コメント追加」ボタンから新規コメント用 Markdown を開き、タイムライン表示の各コメント行をクリックして編集用 Markdown を開けます。
- 設定タブから `settings.json` を直接開けます。

## 並び替えと設定

- 既定順に加えて、優先度・ステータス・トラッカー・担当者・期日・開始日を選べます。項目と昇順・降順は既存の一覧設定に保存し、再読み込み後に復元します。以前に保存された設定も読み込めます。
- 期日（`dueDate`）と開始日（`startDate`）は、選択した項目の有効な暦日（`YYYY-MM-DD`）を比較します。同日は昇順・降順に応じて ID で並べ、未設定・空・不正な日付は両方向とも末尾で ID 昇順に並べます。
- 並び替えは取得済みの絞り込み結果に適用します。通常一覧では同じ階層の兄弟同士を並べ、親子関係を維持します。検索では直接一致の優先を維持します。項目や方向の変更による Redmine への追加リクエストはありません。
- Webview からの入力は [プロトコル](../../src/dashboard/dashboardProtocol.ts) と [検証](../../src/dashboard/dashboardMessageValidation.ts) を通してから処理します。許可外の並び替え項目や方向を持つ `settings.update` は設定を変更しません。
- **Reset Dashboard Cache** は Redmine から再構築可能なデータとメタデータを取り直します。下書き・同期状態・認証情報・設定は保持します。**Reset View State** はレイアウトとクイックフィルターを初期化し、永続のチケット一覧設定を保持します。

実装は [プロジェクトの取得と選択](../../src/dashboard/services/DashboardProjectService.ts)、[チケット取得と検索](../../src/dashboard/services/DashboardTicketService.ts)、[一覧の表示ルール](../../src/views/projectListSettings.ts)、[一覧設定ストア](../../src/views/ticketListSettingsStore.ts) を参照してください。検証は [機能マップ](../../verification/feature-map.json) の `ticket-browsing` と [メンテナンステスト](../../src/test/dashboardMaintenance.test.ts) を参照してください。
