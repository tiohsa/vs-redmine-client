# リファクタリング計画

CodeGraph で呼び出し元を確認し、同期・永続化・Dashboard の大きなモジュールを調査対象とした。実装は下表の順に進め、各タスクで移動前後の呼び出し順、エラー経路、公開 API を照合する。

| 順序 | 対象と調査結果 | 実装単位 | 確認 |
| --- | --- | --- | --- |
| 1 | `operationHandlers.ts` にチケットとコメントの作成・更新が同居 | 操作ごとのハンドラー、共有契約、依存の組み立て、照合と判定を責務別に分ける | 作成・更新、読み戻し、復旧、二重送信の抑止 |
| 2 | `offlineSyncStore.ts` にストレージ形式の変換、トランザクション、操作ごとの状態遷移が同居 | 読み込み時の移行、ライフサイクル判定、破棄・中止を分ける。スコープのトランザクションは更新の入口に据える | 旧形式、スコープ分離、永続化失敗、旧世代の拒否 |
| 3 | `syncRepository.ts` と `syncCoordinator.ts` に照合・通常実行・復旧が集中し、`syncEffects.ts` が Effect の状態遷移と試行終了の判定も扱う | 保存済み操作の変換、世代照合、復旧手順を分ける。Effect の状態遷移と復旧可否、試行終了の判定を責務ごとに整理する | Primary Operation と Effect の原子性、凍結済みリクエスト、再起動時の復旧 |
| 4a | `DashboardController.ts` にメッセージ振り分け、キャッシュの再取得、新規下書きの操作が集まる | 検証済みの要求を処理する境界を保ち、キャッシュの管理と下書き操作を分ける | メッセージ検証、接続切り替え、下書きの作成と同期 |
| 4b | `dashboardWebviewScript.ts` と `dashboardStyles.ts` に複数画面の操作・表示が集まる | Webview を画面と共通処理で分け、スクリプトの初期化順序と CSS の適用順を保つ | 一覧と検索、詳細、未同期操作、キーボードとブラウザー表示 |
| 5a | `commentSaveSync.ts` に文書の保存、結果照合、読み直しが同居し、`conflictResolver.ts` でチケットとコメントの処理が交差 | コメント同期の各段階と、チケット／コメントの競合解決を分ける | Markdown 保存、コメント照合、競合解決の CAS |
| 5b | `DashboardUnsyncedService.ts` と `syncUnsyncedFile.ts` が同期の入口に加えて復旧や通知を扱い、`commandRegistry.ts` に複数機能の登録が集中 | 未同期の実行・通知・対話的復旧を分け、コマンド登録を機能別にする | 明示再試行と中止、コマンドと Dashboard の操作 |
| 6 | `docs/` に機能別の正本と過去の仕様・UI 資料がある | 現行仕様とテストへのリンクを更新し、正本で代替できる資料を削除する | 文書の参照先と機能別仕様を照合する |

公開エントリーポイントから既存の単体テスト、統合テスト、Extension Host テストを実行する。現在のテストで観測できない回帰が見つかった場合は、影響を受ける入口のテストを追加する。Dashboard の分割後は生成された JavaScript と CSS を分割前の出力と照合し、ブラウザー検証で操作と表示を確認する。最後に差分レビューとリポジトリの静的・実行ゲートを通す。

## 実装状況

- [x] 操作ごとの同期ハンドラーと共有部分を分離。チケットの添付送信とコメント添付の復旧で同じ処理を共有する。
- [x] 永続ストアの形式変換・トランザクション・操作種別ごとのキュー更新・状態遷移・Effect 台帳・破棄と中止を分離。
- [x] 同期リポジトリとコーディネーターの復旧処理、Effect の判定と遷移、子チケットの作成・復旧と補償を分離。追加した子チケットの回帰3件を含む Extension Host テストを確認。
- [x] Dashboard のデータ取得・下書き処理と Webview を分離。生成 JavaScript は完全一致し、CSS の差分は旧資料への参照コメントのみ。ブラウザーと Extension Host で検証済み。
- [x] コメントの下書き保存・リモート照合・キュー反映を分離。チケットとコメントの競合解決を分け、文書の適用と巻き戻しを共通化。
- [x] 未同期項目の同期、競合仲介、通知、キュー操作を分離。対話的復旧と機能別のコマンド登録を整理。
- [x] 機能仕様と検証へのリンクを照合し、重複資料8件を削除。差分レビューの指摘を修正し、再レビューと最終検証を完了。
