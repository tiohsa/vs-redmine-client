# Redmine Client サイドバー（ダッシュボード）変更内容まとめ

VS Codeの狭いサイドバー領域における視認性・操作性の向上と、右側Markdownエディタとの機能重複の排除を目的として、以下の通りUI/UXを刷新しました。

---

## 1. ヘッダー・ナビゲーションの省スペース化と役割整理

* **View Header のアクション集約**:
  * 右上に `[更新 (codicon-refresh)]` `[新規作成 (codicon-add)]` `[表示密度切替 (codicon-list-flat)]` を配置し、標準モードと1行コンパクトモードを切り替え可能にしました。
* **プロジェクト選択バーの圧縮**:
  * 「子プロジェクトを含める」のチェックボックス＋ラベルを廃止し、ドロップダウン横の階層アイコンボタン（`codicon-list-tree`）のON/OFFトグルに集約しました。
* **ナビゲーションタブとバッジ統合**:
  * `チケット [総数]` / `未同期 [未同期件数]` / `設定` の3タブ構成とし、従来フッターにあった同期ステータスバーを廃止してタブの件数バッジへ統合しました。
  * 「未同期」クイックフィルタチップを廃止し、タブへの一本化によってフィルタとの二重絞り込み（矛盾）を解消しました。

---

## 2. チケット一覧リストの視認性向上

* **トラッカー別カラーアクセント**:
  * 各チケット行の左端に `3px` のカラーバーを配置し、トラッカー種別を瞬時に判別できるようにしました（`Bug`＝赤系、`Feature`＝緑系、`Task`＝青系）。
* **情報の優先度整理（2行構成＋極細進捗バー）**:
  * **1行目**: 親子展開トグル、等幅フォントのチケット番号（`#3`）、優先度マーカー（`!` / `!!`）、件名。
  * **2行目**: ステータスバッジ、未同期インジケータ、担当者名、期日（期限超過時はエラーカラーで強調）。単一プロジェクト選択時は冗長なプロジェクト名を省略。
  * **底辺**: 進捗率（`done_ratio > 0`）を `2px` の極細プログレスバーで表示。
* **親子階層のツリーガイド表現**:
  * VS Codeのエクスプローラーに倣い、インデントと縦横のツリーガイド線（`--vscode-tree-indentGuidesStroke`）で親子関係を視覚化しました。
* **キーボードナビゲーション対応**:
  * リストフォーカス時の `↑` / `↓` キーでチケット移動・エディタ連動、`Esc` で下部パネルを閉じる操作に対応しました。

---

## 3. 操作フローの簡素化と重複ボタンの廃止

* **シングルクリックで即エディタ表示**:
  * チケット行をクリックすると、選択状態になると同時に**右側エディタで該当チケットのMarkdownファイルを即座に開きます**。これに伴い、不要となった「編集」ボタンを全廃しました。
* **未同期パネルのコンパクト化**:
  * 従来の大見出しや重複する黄色警告枠を廃止し、1行サマリーバー（`未同期 N 件（要確認 M）` ＋ `[すべて同期]` ボタン）へ圧縮しました。
  * カード内の説明文を1行（全文はホバーツールチップ表示）に短縮し、「その他」操作はカード高さを変えないフローティングメニュー（`codicon-ellipsis`）に変更しました。

---

## 4. 下部詳細ドロワーの「コメント専用パネル」化

* **重複情報の削除**:
  * ステータス・優先度・担当者・期日などの「属性グリッド」および「説明本文」は右側エディタに表示されるため、下部パネルから削除しました。
  * これによりサブタブ（「概要」「コメント」の切替）も廃止し、チケット選択時は**最初からコメント一覧・投稿パネル**として広く使えるようにしました。
* **テーマに馴染む自然な階層分離**:
  * 背景色に VS Code 標準の `var(--vscode-editorWidget-background)` を適用し、`1px solid var(--vscode-panel-border)` と微細な上向きシャドウを添えることで、どのテーマ（Dark+ / Light+ / Monokai）でもリスト領域と自然に区別できるようにしました。
* **コメントの追加・編集の統一**:
  * 「＋ コメント追加」ボタンや既存コメントのクリック時は、サイドバー内の狭小な入力欄ではなく、**右側Markdownエディタを開いて快適に編集・同期**するフローに統一しました。
